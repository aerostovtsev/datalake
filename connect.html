Подключение к datalake

Используйте клиент с поддержкой удалённых MCP-серверов и OAuth. Вход выполняется рабочей учётной записью. Динамическая регистрация клиентов выключена, поэтому указанный Client ID обязателен.

  • Адрес сервера: https://mcp-data-lake.first-bit.ru/mcp
  • OAuth Client ID: 389975564900892674

Claude Code

Выполните команду в терминале:

claude mcp add --transport http datalake \
  https://mcp-data-lake.first-bit.ru/mcp \
  --client-id 389975564900892674 -s user

Откройте Claude Code и выполните /mcp, чтобы пройти авторизацию для datalake. После подключения начните новую сессию.

Codex CLI

Добавьте сервер и выполните вход:

codex mcp add datalake \
  --url https://mcp-data-lake.first-bit.ru/mcp \
  --oauth-client-id 389975564900892674
codex mcp login datalake

Список настроенных серверов показывает codex mcp list. Затем начните новую сессию Codex.

OpenCode

В новый файл ~/.config/opencode/opencode.json вставьте этот JSON. Если файл уже существует, добавьте только запись datalake в его раздел mcp, сохранив остальные настройки.

{
  "mcp": {
    "datalake": {
      "type": "remote",
      "url": "https://mcp-data-lake.first-bit.ru/mcp",
      "enabled": true,
      "oauth": { "clientId": "389975564900892674" }
    }
  }
}

Сохраните файл, затем отдельно выполните в терминале:

opencode mcp auth datalake

Пройдите вход в открывшемся браузере и перезапустите OpenCode. Команда opencode mcp debug datalake помогает проверить подключение.

Cursor, Claude Desktop и ChatGPT

В настройках удалённого MCP-сервера или коннектора укажите адрес сервера и OAuth Client ID из начала этой страницы. Названия и доступность настроек зависят от клиента и версии. После сохранения пройдите вход рабочей учётной записью и начните новую сессию.

Если подключение не получилось

  • Ответ 401 missing access token при открытии адреса MCP в обычной вкладке ожидаем: вход выполняется из MCP-клиента.
  • Ошибка о неподдерживаемой динамической регистрации означает, что клиент не передал указанный OAuth Client ID.
  • Если сервер недоступен, проверьте доступ к корпоративной сети или VPN.
  • Если после входа сервер отклоняет адрес возврата, передайте администратору название клиента и показанный callback URL. Не передавайте токены.

Для первой проверки спросите агента: «Какие данные есть в базе?» — он должен вызвать инструмент describe_data.
